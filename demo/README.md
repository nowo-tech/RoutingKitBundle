# Routing Kit Bundle demos

## Symfony 8 (FrankenPHP)

```bash
make up-symfony8
```

Open http://localhost:8058 — panel at http://localhost:8058/_routing

Sample pages: `/about`, `/blog/hello-world`. Marked with `#[Routable]` for the CRUD.

See [docs/DEMO-FRANKENPHP.md](../docs/DEMO-FRANKENPHP.md) and [docs/USAGE.md](../docs/USAGE.md).
